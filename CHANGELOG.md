# Changelog

## 2.0.0

- Public, user-agnostic release under the **Second Brain** name.
- Removed personal hard-coded names and machine-specific defaults.
- Added `--name`, `--language`, `--path`, and `--checkpoint-minutes` configuration.
- Default local vault is now `~/Documents/Second Brain`.
- Shared global adapters for Claude Code, Codex, and OpenCode.
- Historical Claude/Codex transcript import with immutable raw backups.
- History compiler for projects, decisions, concepts, entities, syntheses, rules, and threads.
- GitHub Actions CI, MIT license, English/Turkish README files, and package verification.
